## 2. Output (`<dir>`)

All PNGs: colour type 3, depth 8, **raw engine indices** (no ipack rotation), PLTE = effective palette 0 with all 256
entries (`Hires::effective_palette0`, the R1 palette, `min(255, v·255/63)`), written by `Hires::write_indexed_png`
(filter none, zlib 9, no time chunk), so bytes are deterministic.

| `terrain.txt` | `tnum t1 uses own_cells rle_cells missing_cells duplicate_of same_layer` for **every** terrain (also unused ones; 4 `#` header lines). `uses`: map chunks (all maps); `own_cells`: tiles of kind Flat/Flat_void; `rle_cells`: kind Rle; `missing_cells`: cells with no source (left 0 by P3); `duplicate_of`: the canonical terrain of the key, or `-`; `same_layer`: 1/0 whether this terrain's 1x layer equals the canonical one, `-` for the canonical |
| `terrain_tiles.bin` | header + per terrain (2048 bytes): 256 × own `{shape u16, frame u8 (raw ShapeID frame), kind u8 (Tile_kind: 0 None, 1 Flat, 2 Flat_void, 3 Rle)}`, then 256 × effective source `{shape u16, frame & 31 u8, source tile u8}` (`ffff ff ff` = none) |
| `terrain_map.bin` | header + per map (73,732 bytes): `{map number u32, 192×192 u16 terrain numbers, cy outer, cx inner}` (Python: `[cy, cx]`, the layout of `u7hires.io.parse_map`) |
| `manifest.txt` | (added by the review fix, §7) `crc32 size path` of every file above but `ref.txt` and itself, read back from disk |

Binary header (16 bytes, little-endian): `"U7HR"`, version u16 = 1, type u16 (1 = terrain_tiles, 2 = terrain_map),
record size u32, record count u32; the file size is `16 + size × count`.

Maps: map 0 plus every further map `Find_next_map` finds (`<STATIC>/mapNN` or `<PATCH>/mapNN`, probing 10 ahead as the
cheat screen does). BG has map 0 only.

**Output directory policy.** Created when missing. An existing non-empty directory must hold an earlier dump
(`ref.txt` with `format=exult-dump-art/1`); then only the dump's own entries are removed and rewritten, anything else is
left alone. Since the review fix (§7) the run is refused (exit 2) while an entry holds a file the earlier
`manifest.txt` does not list or whose size/CRC changed, or when the earlier dump has no manifest. Otherwise, or when the directory lies inside `<STATIC>` (canonical paths, trailing separators handled), the
run is refused with exit code 2 before anything is written. (An interrupted dump has no `ref.txt` and must be deleted
by hand.)

## 4. Deviations from the spec (the code is the truth)

1. **Formats the spec leaves open were fixed here** (§2): the `U7HR` header (16 bytes: magic, version, type, record
   size, count), the effective-source triple `{shape u16, frame & 31 u8, source tile u8}` with `ffff/ff/ff` for none, a
   `u32` map number in front of each `terrain_map.bin` record, `ref.txt` as `key=value` (so the existing
   `u7hires.pack.palette_crc_from_ref` reads it), `classes.txt` as `xx class`.
2. **Extra columns / keys:** `terrain.txt` has an 8th column `same_layer` (§8.4 B2 wants to skip duplicate keys whose
   fills differ; for BG there are none). `ref.txt` carries more keys than §4.2 lists (`format`, `game_variant`, counts,
   `patch_*`, `bad_terrain_refs`). `flats.txt` keeps exactly the spec's columns; their meaning is in its header.
3. **`game=BG` + `game_variant=FOV`** rather than `game=FOV`: `pack.txt` names the game type (`game=BG`), FoV and BG share
   the art keys.
4. **Canonical terrain of a T1 key** (whose layer becomes `terrain/<t1>.png`): the first **used** terrain with that key,
   else the first one — not specified in §4.2.
5. **`templates/pack.txt`** added, so the templates are a loadable identity pack (O4a) as they are; `dump_art.sh`
   proves it. `mkpack_identity.py` (WP-09) is unchanged: it can now be replaced by the templates where a dump exists, and
   §9 WP-12's `mkpack` should copy `palette_crc32` from `ref.txt`.
6. **Template scale is fixed at 6** (the `x6` of §4.2), not read from `config/video/hires/art_scale`.
7. **Output directory policy** (§2): refuse a non-empty directory without an earlier dump and anything inside `<STATIC>`;
   not in the spec.
8. **(Superseded by §7, W11-1: the parity is now in the tree.)** **The T1/fill parity test is not in the `hires` tree**: `u7hires` lives on `hires-art` and is not merged yet, so the
   parity run is `tmp/wp11/parity.py` (scratch, uses the art worktree read only). In-tree, `dump_art.sh` +
   `dump_art_check.py` check determinism, completeness, flat CRCs and palette CRC (via `mkpack_identity.py`), the tables
   against `u7chunks`/`u7map` and the templates in the engine. WP-12 (`u7hires/ref.py`) should turn `parity.py` into a
   pytest once the art tools are merged.
9. `--dump-art` writes no `missing_cells.txt` (proposal C); `terrain.txt`'s `missing_cells` and the `ffff` entries of
   `terrain_tiles.bin` carry the same information.
